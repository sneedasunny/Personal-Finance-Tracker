# Personal Finance Tracker

## About the Project
A desktop-based Personal Finance Tracker developed using Java Swing to help users manage and monitor their financial transactions.

## Features
- User login interface
- Add and manage financial transactions
- Store transaction records using SQLite
- Organise transactions by category
- Visualise financial data using charts

## Technologies Used
- Java
- Java Swing
- SQLite
- SQLite JDBC
- JFreeChart

## Project Structure
- `Main.java` – Application entry point
- `LoginFrame.java` – Login interface
- `MainFrame.java` – Main application interface
- `AddTransactionDialog.java` – Transaction entry interface
- `DBHelper.java` – Database connectivity
- `Transaction.java` – Transaction data handling
- `PieChartPanel.java` – Financial chart visualisation
